# learn-openfast
120-hour self-taught OpenFAST course for students interested in learning more about wind turbine simulations.

I am learning how to use OpenFAST. I thought I would keep a repository of my lessons, simulations, exercices, and assessments. I would like to be comfortable with the modules most relevant to my research within 8 weeks. I plan on spending 12-15h a week learning.

[Eight-week syllabus](syllabus.md) | [Environment](environment.md) | [Progress](progress.md)

**[Start Week 1](lessons/week-01/lesson.md)** — daily lessons, exercises, and assessment.

## Structure

- `lessons/`: lesson notes, exercises, and assessments; start with `week-01/`.
- `work/`: your predictions, notebooks, and answers, organised by week.
- `models/`: documented OpenFAST baseline and exercise inputs.
- `scripts/`: reusable simulation and analysis utilities.
- `reports/`: concise findings and selected figures.
- `runs/`: generated simulation outputs, excluded from Git.
